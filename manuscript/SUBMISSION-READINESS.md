# Submission-readiness checklist

## Complete evidence

- [x] Strict receptor-preparation audit and versioned tables.
- [x] Two separate reference-pose recovery campaigns.
- [x] Source, prepared-input, configuration, and output checksums.
- [x] All-pose result tables and stated limitations.
- [x] Deterministic repository checks in CI.

## Required before journal submission

- [ ] Authors approve the complete manuscript text and contribution statement.
- [ ] References are formatted for the selected journal and checked against primary sources.
- [ ] Journal-specific formatting, figure resolution, and citation style are applied.
- [ ] A human-led language and technical review is completed.
- [ ] Data/code availability wording is checked against the final public release.
- [ ] No claims extend beyond the documented computational evidence.
