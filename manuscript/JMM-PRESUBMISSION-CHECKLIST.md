# JMM pre-submission checklist

Status: preparation complete where marked; this file is not a submission authorization.

## Completed preparation

- [x] Software Report manuscript source prepared in English with the required structured abstract headings.
- [x] Author names, affiliations, correspondence address, and ORCID identifiers recorded for the three authors.
- [x] Frozen v0.2.0 Zenodo archive DOI recorded without claiming that it contains later comparator artefacts.
- [x] Reproducibility protocols, non-coordinate result tables, checksums, and deterministic SVG figures retained in the repository.
- [x] Direct PDB, mmCIF, legacy-PDB comparator, and reference-pose recovery claims linked to retained evidence.

- [x] Declarations for funding, competing interests, authorship, data availability, and AI-assisted computational support included for review.

## Required immediately before portal submission

- [ ] All authors approve the exact final manuscript, title, author order, CRediT statement, declarations, and uploaded figure files.
- [ ] Create and verify a new versioned public archive for the comparator and manuscript-source state; insert its DOI or version URL in the final manuscript.
- [ ] Produce the journal-upload figure derivatives from the retained SVG source files in the format requested by the portal, while retaining the vector originals.
- [ ] Re-run the documented environment and evidence-verification commands at the tagged release candidate commit.
- [ ] Confirm the selected publication route and any fee waiver or charge conditions directly in the journal portal.
- [ ] Confirm that the work is not under consideration elsewhere and complete any journal-specific declaration truthfully.
- [ ] Enter bilingual or journal-required metadata manually in the submission portal and check the generated proof.

## Guardrails

No journal submission, Zenodo publication, software release, tag, payment, or public metadata change is authorized by this checklist alone. Each is a distinct external action requiring final author confirmation.
